## 무엇을 다루나

**1부 — 개념 · 시연 · 해부**

1. 왜 지금인가 — 기대와 불신 사이, 그럴듯하게 틀리는 오류
2. 에이전트란 무엇인가 — 부품과 자율 루프, 오늘의 도구
3. 무슨 일을 맡길 수 있나 — 동향조사 공정, 팀 구조, 예결위 업무 적용
4. 부품을 뜯어본다 — CLAUDE.md · 스킬 · 명령어 · 훅 · API · MCP
5. 틀리면 안 되는 것을 규칙으로 굳힌다 — 급소 지도 · 검산 게이트 · 출처 우선순위

**2부 — 실습**

앱 설치 → 작업 폴더 → 교정 스킬 설치·실행 → 보고서 쓰는 AI 팀 설치·가동 → 내 업무용 기획안.
프롬프트마다 복사 버튼이 붙어 있어 그대로 붙여 넣으면 됩니다. 터미널은 쓰지 않습니다.
